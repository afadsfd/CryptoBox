# 非现货资产支持口径优化

- **日期**: 2026-05-19
- **项目**: 资产聚集app
- **阶段**: 运行中
- **标签**: #资产聚合 #交易所API #合约 #理财 #产品口径

## 本次任务踩的坑

### 坑 1: 统一账户被误标成现货
- **现象**: OKX、Bybit 的统一账户结果原来容易落在 `spot` 展示口径下。
- **原因**: 交易所统一账户本身混合现货、合约、杠杆、期权保证金，三分类不足以表达真实含义。
- **解决方案**: 新增 `unified`、`funding`、`futures_usdt`、`futures_coin` 等细分来源。
- **预防措施**: 新交易所接入前先定义资产来源，不按接口函数名直接判定资产类型。
- **是否可复用**: 可复用，多交易所资产聚合都适用。

### 坑 2: 产品文案容易过度承诺
- **现象**: 官网原来使用“全部加密资产”等表达，和真实 API 覆盖边界不完全一致。
- **原因**: 现货支持相对标准，但理财、资金账户、合约、期权等非现货资产因交易所差异无法统一承诺。
- **解决方案**: 文案改成“核心加密资产”“现货为基础能力，合约 / 理财 / 资金账户按交易所接口逐步增强”。
- **预防措施**: 对外文案必须和支持矩阵一致。
- **是否可复用**: 可复用，尤其适合金融类产品。

### 坑 3: 当前环境缺少 Flutter / Dart 命令
- **现象**: 执行 `dart format`、查找 `flutter`、`fvm` 均失败。
- **原因**: 当前 shell PATH 内没有 Flutter SDK。
- **解决方案**: 已先完成 `git diff --check` 和代码级自查；完整 `flutter analyze/test` 需要恢复 Flutter SDK PATH 后补跑。
- **预防措施**: Flutter 项目应在 README 或启动脚本里固定 SDK 路径或 fvm 配置。
- **是否可复用**: 可复用，所有本地 Flutter 项目都应避免“只在某个终端 profile 可用”的环境假设。

## 本次实现的优化

### 优化 1: 资金来源细粒度化
- **优化前**: 只有 `spot / earn / futures`。
- **优化后**: 增加 `funding / earn_flexible / earn_locked / futures_usdt / futures_coin / futures_usdc / unified / margin / options / unknown`，并保留旧值兼容。
- **收益**: 资产展示口径更真实，后续排查非现货资产缺口更容易。
- **代价**: 数据模型和 UI 需要处理更多来源标签。
- **是否可复用**: 可复用。

### 优化 2: 交易所资产支持矩阵
- **优化前**: 页面只展示交易所是否可连接。
- **优化后**: 交易所卡片和添加 API 页面展示资产支持范围、支持等级和备注。
- **收益**: 用户连接前就知道哪些资产是稳定支持、哪些只是 Beta 或待补。
- **代价**: 需要跟随交易所 API 变化维护矩阵。
- **是否可复用**: 可复用。

### 优化 3: 首页同步完整度提示
- **优化前**: 首页只显示资产来源分组和笼统同步警告。
- **优化后**: 每个交易所分组显示“已识别 X/Y 类”和最后同步时间。
- **收益**: 用户能快速判断当前聚合是否可能漏掉某些非现货资产。
- **代价**: 当前仍以“已识别有余额的来源”为主，零余额来源无法证明接口成功。
- **是否可复用**: 可复用。

## 学到的可复用知识

### 知识点 1: Capability Matrix 比硬编码支持布尔值更可靠
- **场景**: 多交易所、多钱包、多数据源聚合。
- **要点**: 不只记录“是否支持”，还要记录“支持到什么程度、是否 Beta、需要什么权限、是否存在口径限制”。
- **示例**:

```dart
ExchangeAssetSupport(
  source: BalanceSource.unified,
  level: AssetSupportLevel.partial,
  note: '统一账户混合现货/合约/杠杆/期权净值',
)
```

### 知识点 2: 存库字段要用稳定 key，不要直接依赖 enum.name
- **场景**: Dart enum 重命名、前端本地库迁移、旧数据兼容。
- **要点**: 用 `storageKey` 统一输出，读入时用解析函数兼容旧值。
- **示例**:

```dart
source: Value(balance.source.storageKey);
final source = balanceSourceFromStorage(row.source);
```
